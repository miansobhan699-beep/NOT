## Update your existing GitHub repository

1. Extract this ZIP on your computer.
2. In your GitHub repository, choose **Add file → Upload files**.
3. Upload `index.html`, `.nojekyll`, `README.md`, and all six `memory-*.jpg` files together.
4. Commit the changes to `main`.
5. Open **Settings → Pages** and ensure source is **Deploy from a branch**, branch `main`, folder `/(root)`.
6. Open the published site and press **Ctrl + F5** to bypass cached files.

Important: Keep all six `memory-*.jpg` files in the same root level as `index.html`. Do not put them in an `images` folder for this version.
