# Antel Hayat — Rehan's Love Website

A static, responsive romantic website made for GitHub Pages.

## Repository structure

Upload these files and folders to the **root** of your GitHub repository:

```text
/
├── index.html
├── .nojekyll
├── README.md
└── images/
    ├── memory-1.jpg
    ├── memory-2.jpg
    ├── memory-3.jpg
    ├── memory-4.jpg
    ├── memory-5.jpg
    └── memory-6.jpg
```

## Publish with GitHub Pages

1. Open your GitHub repository.
2. Choose **Add file → Upload files**.
3. Extract this ZIP on your computer.
4. Upload `index.html`, `.nojekyll`, `README.md`, and the complete `images` folder. Keep the folder structure exactly as shown.
5. Commit the files to the `main` branch.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch **main** and folder **/(root)**, then click **Save**.
9. Wait for GitHub Pages to publish; the site URL will appear in Settings → Pages.

## Important

- Do not upload the ZIP itself as the website; extract it first.
- Do not upload only `index.html`; the `images` folder is required.
- Keep the file name `index.html` lowercase and in the repository root.
- All image links are relative, so the site works in a GitHub project repository path.
- Google Fonts require an internet connection; local fallback fonts are included.
